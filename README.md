# 🎧 TuneIn App

**ITRACKA3 – Platform Technologies: Data-Driven Mobile Application**

## 📌 Overview

TuneIn is a premium, data-driven mobile application simulating a modern music streaming platform. Users can explore curated tracks, search categories, construct custom playlists, manage subscriptions, download music for offline playback, and control playback through a sleek, dynamic interface.

## 🚀 Key Features

*   🔐 **Secure Authentication**: Implements robust registration, login, and comprehensive account/profile deletion using Firebase Auth and Firestore.
*   🎵 **Premium Music Player**: Smooth full-screen player and persistent mini-player with background playback capability, dynamic audio controls, and progress tracking.
*   🔍 **Advanced Category Search**: Explore and filter the music catalog with dynamic genre chips and lightning-fast search queries.
*   📂 **Custom Playlists**: Create, add, remove, and delete playlists with synchronized real-time state management.
*   💾 **Offline Downloads**: Simulated premium tier downloads to device storage using local SQLite buffers for uninterrupted playback.
*   📈 **Admin Dashboard**: Comprehensive upload pipeline supporting binary chunk uploads of MP3 files and cover artwork.
